## 📌 Project Overview
This project contains SQL queries to analyze a bookstore dataset.

- PostgreSQL
- SQL

- Track orders and sales
- Identify most expensive books
- Stock analysis

## 📁 Files
- bookstore.sql → Contains all SQL queries

## 🚀 Purpose
To practice SQL queries and extract meaningful insights from data.
